Features
BFS (Breadth First Search) Visualization
DFS (Depth First Search) Visualization
Start and End Node Selection
Wall Creation
Random Maze Generator
Visited Nodes Counter
Path Length Counter
Real-time Algorithm Status
Interactive Grid Interface
How to Use
Click any cell to set the Start Node.
Click another cell to set the End Node.
Click cells to create walls.
Or use the Generate Maze button.
Select BFS or DFS.
Click Run Algorithm.
Blue cells represent visited nodes.
Yellow cells represent the final path.
Use Reset to start again.
Technologies Used
HTML5
CSS3
JavaScript (ES6)
Algorithms Implemented
BFS (Breadth First Search)
Finds the shortest path in an unweighted grid.
Explores nodes level by level.
DFS (Depth First Search)
Explores as deep as possible before backtracking.
May not always return the shortest path.
